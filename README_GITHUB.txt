طريقة الرفع الصحيحة:

1. فك الضغط عن هذا الملف.
2. افتح المجلد الناتج الذي بداخله index.html.
3. ارفع الملفات الموجودة بداخله مباشرة إلى جذر مستودع GitHub.
4. يجب أن يظهر index.html بجانب مجلدي assets و manus-storage.
5. لا ترفع ملف ZIP نفسه، ولا تضع الملفات داخل مجلد dist أو مجلد آخر.
6. في Settings > Pages اختر main ثم /(root).
